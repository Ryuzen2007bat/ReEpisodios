Política de privacidad de Re:Episodios

Re:Episodios es una página personal sin fines comerciales para ponerle un título a cada día. Esta política explica qué datos usa, dónde se guardan y cómo borrarlos.

Qué datos se guardan

Solo lo que tú escribes en la página:

  • El título de cada día y la memoria opcional que lo acompaña.
  • Las rutas que creas, sus nombres y colores.
  • Las fechas de cada página y de cuándo se editó o se borró.

La página no pide ni guarda tu nombre, tu correo, tus contactos ni ningún otro dato de tu cuenta de Google.

Dónde se guardan

  • En tu navegador (almacenamiento local del dispositivo), para que la página funcione incluso sin internet.
  • En tu propio Google Drive, si eliges conectar tu cuenta, dentro de una carpeta oculta de la aplicación (appDataFolder). Ese archivo solo puede leerlo esta página; no aparece entre tus archivos de Drive ni lo pueden abrir otras aplicaciones.

No existe ningún servidor propio: el desarrollador no recibe, no almacena y no puede ver lo que escribes.

Permiso de Google que se solicita

La página solicita únicamente el permiso drive.appdata ("Ver, crear y borrar sus propios datos de configuración en tu unidad de Google Drive"). Se usa exclusivamente para leer y guardar el archivo de tu Libro en la carpeta oculta de la aplicación. No se accede a ningún otro archivo de tu Drive.

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado. Estos datos no se venden, no se comparten con terceros y no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

Servicios de terceros

  • GitHub Pages aloja la página.
  • Google Identity Services gestiona el inicio de sesión cuando eliges conectar tu cuenta.
  • Google Fonts entrega la tipografía de los títulos.

Como con cualquier sitio web, estos servicios pueden registrar datos técnicos de la conexión (por ejemplo, la dirección IP) según sus propias políticas de privacidad. La página no usa cookies propias, analíticas ni publicidad.

Cómo borrar tus datos

  • Para borrar páginas o rutas sueltas: usa "Quemar página" o "Borrar ruta" dentro de la aplicación.
  • Para quitarle el acceso a tu cuenta: entra a las conexiones de tu cuenta de Google y elimina el acceso de la aplicación.
  • Para borrar el archivo guardado en Drive: en la configuración de Google Drive, entra a Administrar aplicaciones, busca esta aplicación y elige Borrar datos ocultos de la aplicación.
  • Para borrar lo guardado en el navegador: elimina los datos del sitio desde la configuración de tu navegador.
